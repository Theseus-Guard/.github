## TG-Sentinel:G1

TG-Sentinel:G1 is our governance foundation model for real-time AI and agent oversight. A unified 7+1 Mixture-of-Experts (MoE) model supports configurable **Fast**, **Max**, and **Ultra** evaluation modes, alongside **Cyber** security-verification and **Raw** technical-reporting modes.

In Theseus Guard's company-reported pre-production holdout evaluation (4,050 tier evaluations), G1 achieved strict decision accuracy of **94.61% (Fast)**, **95.31% (Max)**, and **95.38% (Ultra)**. The published benchmarks also report sub-60 ms time-to-first-token and 14,000+ generated tokens/second on 2× NVIDIA H100 GPUs. Results depend on evaluation methodology and serving hardware; these are company-reported, not independent third-party results.
